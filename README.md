# 云笺 CloudNote

> 把想法，写在一起。

一个类飞书的轻量级在线协作文档编辑器：支持富文本、图片 / 视频 / GIF、划线评论、多人协作、对外分享与完整的账号权限体系。单进程部署，自带数据库，开箱即用。

## 一、项目概述

**云笺**是一款自研的在线文档产品，目标是做一个「够轻、够美、够用」的协作写作工具：

- **轻**：零前端框架、零构建工具，纯原生 HTML/CSS/JS + 单文件 Node 服务端，整个项目核心只有 3 个文件；数据库用 SQLite（sql.js 纯 WASM 实现），不需要安装任何数据库服务。
- **美**：Apple 风格设计语言——毛玻璃工具栏、SVG 线性图标、品牌蓝紫 `#5264E8`、克制的信息层级。
- **用**：覆盖「写 → 评 → 享 → 协作」完整闭环，并内置粘贴净化、媒体排版、权限模型等真实产品细节。

### 核心功能

| 模块 | 说明 |
|---|---|
| 富文本编辑 | 标题 / 加粗斜体 / 列表 / 引用 / 代码块 / 分割线 / 文字颜色 / 高亮，`/` 快捷插入菜单，自动保存（700ms 防抖） |
| 媒体 | 图片（含 GIF）、视频上传（≤200MB），自然尺寸居中 + 12px 圆角 + 轻投影，宽度一键调节，可加图注 |
| 划线评论 | 选中文字即出评论框（类飞书），支持给图片 / 视频评论；右侧常驻评论面板；Enter 直接发送 |
| 评论归档 | 已解决评论不删除，归档保存并可查看「修改前 vs 修改后」对比、解决人、时间 |
| 多人协作 | 版本号轮询同步（2s）+ 在线协作者头像（5s 心跳）；编辑冲突检测（409），后保存者胜 |
| 对外分享 | 每篇文档独立分享链接，三档权限：关闭 / 只读 / 可编辑 |
| 账号系统 | 手机号 + 密码注册登录（scrypt 加盐散列），Cookie 会话（30 天），预留微信 / 飞书 / 企业微信 OAuth 绑定接口，多登录方式关联同一账号 |
| 权限模型 | 创建文档需登录；文档默认私有仅作者可见；分享是唯一开放口子；匿名可浏览可评论，编辑需登录 |
| 粘贴净化 | 外部内容（飞书 / 网页 / 微信文章）粘贴自动清洗：标题降级、剥样式、拆包装标签、表格摊平、裸图归位为媒体块 |
| 其他 | 左侧文档目录（TOC）、「我写的 / 浏览过」文档管理、文档导出 HTML、访客无需登录即可阅读评论 |

## 二、技术架构

```
┌──────────────────────────────────────────────┐
│  浏览器 SPA（原生 JS，无框架）                  │
│  public/index.html  编辑器 + 侧栏 + 评论面板    │
│  public/share.html  对外只读分享页             │
└──────────────┬───────────────────────────────┘
               │ REST API（fetch）
┌──────────────▼───────────────────────────────┐
│  Node.js 服务端  server.js（单文件）           │
│  Express + multer（上传）+ sql.js（WASM SQLite）│
├──────────────────────────────────────────────┤
│  数据（自动建库 / 自动迁移）                     │
│  data/lite-doc.db   docs / comments / users   │
│                     identities / sessions ...  │
│  uploads/           媒体文件落盘               │
└──────────────────────────────────────────────┘
```

**选型理由**

- **sql.js 而非 better-sqlite3**：纯 WASM 无原生编译，在任何受限沙箱 / Serverless 环境都能直接跑，代价是写库需要手动持久化（已封装 `schedulePersist` / `persistNow`）。
- **版本号轮询而非 WebSocket / OT**：单端口 HTTP 部署友好，实现简单可靠；409 冲突 + 强制覆盖兜底，牺牲理论实时性换取可维护性。
- **contenteditable + execCommand**：零依赖获得可信的富文本编辑能力，配合粘贴净化器保证内容干净。

## 三、快速开始

```bash
# 1. 安装依赖（只有 3 个）
npm install

# 2. 启动（默认端口 3000，可用 PORT 环境变量覆盖）
npm start
# 或
PORT=3456 node server.js

# 3. 打开 http://localhost:3000
```

首次启动自动建库建表；已有旧库自动迁移（新增列自动补齐，数据无损）。

### 配置第三方登录（可选）

复制 `config.json` 中的模板，填入对应平台的 appId / appSecret 即可启用：

- **飞书**（最易接入）：open.feishu.cn 创建自建应用，回调地址填 `https://<域名>/api/auth/feishu/callback`
- **微信扫码**：需企业资质 + ICP 备案域名
- **短信**：默认 dev 模式，验证码直接回显在登录框（方便调试）

不配置不影响使用——手机号 + 密码登录开箱即用。

## 五、API 概览

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/auth/register` | 公开 | 手机号 + 密码 + 用户名注册（已登录时=绑定到当前账号） |
| POST | `/api/auth/login` | 公开 | 手机号 + 密码登录 |
| GET | `/api/me` | 会话 | 当前用户信息 |
| GET | `/api/docs` | 登录 | 我创建的文档列表 |
| POST | `/api/docs` | 登录 | 新建文档（默认私有） |
| GET/PUT/DELETE | `/api/docs/:id` | 见权限模型 | 读取 / 保存（带 baseRev 冲突检测）/ 删除 |
| PUT | `/api/docs/:id/share` | 仅作者 | 分享设置 off / view / edit |
| GET/POST | `/api/docs/:id/comments` | 可读即可评 | 评论列表 / 发表评论 |
| POST | `/api/comments/:id/resolve` | 可读 | 解决评论（归档 + 前后对比） |
| POST | `/api/upload` | - | 媒体上传（multer，≤200MB） |
| POST | `/api/docs/:id/presence` | - | 在线协作者心跳 |

**权限模型一句话**：读 = 作者或已分享；写 = 作者，或 edit 分享下的登录用户；管理（删除/改分享）= 仅作者。`owner_id` 为空的历史匿名文档保持公开兼容。

## 六、部署

任意支持单端口 HTTP 服务的平台均可部署（PaaS / 容器 / 云主机）：

- 服务监听 `PORT` 环境变量并绑定 `0.0.0.0`
- 数据持久化依赖磁盘（SQLite 文件 + uploads 目录），请挂载持久卷
- `npm install && npm start` 即为完整启动命令
